# INFORMS 2026 DMS Data Challenge — experiment dashboard

An interactive view over the 210 models built for the challenge: every model
sortable by score and family, the shipped members plotted by accuracy against
error correlation, and a builder that returns the exact held-out score of any
subset of 60 models you combine.

**→ [Open the dashboard](https://hamedkhosravi99.github.io/informs2026-dashboard/)**

Team **Bee2** — Hamed Khosravi (team leader), Melika Baghi.

The full code, the experiment catalogue in four formats, and the written report
are in a separate repository that becomes public on 25 September 2026, once the
competition deadline has passed.

No competition data is included here or in the linked page.
